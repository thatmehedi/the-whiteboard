# Canvas Corner

A cheerful, dependency-free browser whiteboard for quick notes and sketches.

## Use it

Open `index.html` in any modern browser. No install or build step is needed.

- Draw freely with the pen and choose from a rich color palette (black, coral, blue, ocean blue, green, mint, orange, purple, pink, slate).
- Switch to **Text**, click the board, and enter a note.
- Erase parts of a drawing, undo the latest changes, or clear the board.
- Use **Save PNG** to download your work with a timestamped filename and paper-colored background.

## Keyboard Shortcuts

- **P** — Pen tool
- **E** — Eraser tool
- **T** — Text tool
- **Ctrl + Z** / **Cmd + Z** — Undo action

## Project files

- `index.html` — application structure and controls
- `styles.css` — responsive visual design
- `app.js` — canvas drawing and whiteboard behavior
